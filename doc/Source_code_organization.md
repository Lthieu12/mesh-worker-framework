# Source Code Architecture

The MMF repository is organized to clearly separate the framework implementation, documentation, examples, development tools and tests.

```
mesh-worker-framework/
├── doc/
├── examples/
├── scripts/
├── src/
│   └── dev_support/
├── tests/
├── Cargo.toml
└── ...
```

---

## `doc/`

Project documentation.

This directory contains architecture descriptions, development guides and design notes that complement the API documentation generated by Rust.

Typical contents include:

- framework architecture
- development documentation
- implementation notes

---

## `examples/`

Example applications demonstrating how to use MMF.

Examples serve both as:

- executable documentation;
- integration examples for framework users.

They are automatically compiled during the verification process.

---

## `scripts/`

Development helper scripts.

These scripts are **not part of the framework itself** but simplify common development tasks.

Current scripts include:

- `verify.ps1` — verifies the framework on both Windows and Linux (WSL2);
- `git_push.ps1` — stages, commits and pushes repository changes.

---

## `src/`

Framework source code.

This directory contains the complete MMF implementation.

The source is organized into independent workers, each responsible for a specific framework component.

Examples include:

- runtime management;
- worker lifecycle;
- messaging;
- logging;
- error handling;
- registries;
- utility functions.

---

### `src/dev_support/`

Development-only helper workers.

These components are used exclusively for testing and examples and are **not intended for framework users**.

Typical contents include:

- simulation workers;
- test helpers;
- development utilities.

---

## `tests/`

Integration tests.

These tests validate the framework from a user's perspective through its public API.

Unlike unit tests, integration tests interact with MMF exactly as an external application would.

---

## `target/`

Default Cargo build directory.

This directory contains compilation artifacts produced during normal development.

It is automatically generated by Cargo.

---

## `target-windows/`

Temporary build directory used by the cross-platform verification script when building under Windows.

---

## `target-linux/`

Temporary build directory used by the cross-platform verification script when building under Linux (WSL2).

---

## Root files

### `Cargo.toml`

Rust package manifest.

Defines:

- crate metadata;
- dependencies;
- features;
- build configuration.

---

### `build.rs`

Build script executed automatically by Cargo before compilation.

Used to generate build-time information required by MMF.

---

### `README.md`

Project overview.

Introduces MMF, explains its goals and provides basic usage instructions.

---

### `rustfmt.toml`

Project formatting configuration.

Defines the formatting rules used by `cargo fmt`.

---

### `.gitignore`

Lists files and directories ignored by Git, including compilation artifacts and temporary files.
